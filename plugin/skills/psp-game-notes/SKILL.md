# Game notes

Read the matching file before touching a game, and append new findings (with evidence and date) after every session.

- `references/initial-d-street-stage.md` — ULJM05093, Sega 2006
- `references/wangan-midnight-portable.md` — ULJM05264, Genki/Namco 2007

When a new game is decompiled, create `references/<slug>.md` with: identity (disc ID, version, firmware), code (BOOT/EBOOT state, sections), filesystem summary, container/compression formats, where cars/courses/menus/text/fonts/music live, known tables (offset, stride, count), open problems.
